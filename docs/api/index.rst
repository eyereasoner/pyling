pyling documentation
====================

``pyling`` is the Python implementation of the Eyeling Notation3 reasoner. It
provides an N3 reasoning API, RDFLib interoperability, RDF 1.2 and RDF Message
support, extensible built-ins, and in-memory or persistent fact stores.

Install the package from PyPI:

.. code-block:: console

   python -m pip install pyling-n3

For practical, executable introductions, see the `pyling notebooks
<../index.html>`_.
